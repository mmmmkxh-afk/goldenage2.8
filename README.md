# Golden Age Residential Care

A modern, responsive landing page concept for senior assisted living and memory care.

## Features
- **Interactive 3D Virtual Tours**: Explore sample room, kitchen, and living room previews.
- **Accessibility Details**: Highlights wheelchair accessibility, step-free entrances, and mobility support.
- **Viewing Request Form**: Online tour scheduling system.
- **Interactive Assistant**: Interactive screening and FAQ assistant widget.
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices.

## Running Locally
You can view the site locally by opening `index.html` in any browser or running:
```bash
python3 -m http.server 3000
```
Then visit `http://localhost:3000`.
